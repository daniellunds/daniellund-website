# Koteudregner (Lab-underprojekt)

Denne side er lavet ud fra formlerne i `Koteberegning.xlsx`:

- **Højde**: `h = (‰/1000) * L`
- **Længde**: `L = h / (‰/1000)`
- **Hældning**: `‰ = (h / L) * 1000`

## Placering i daniellund.dk

Forslag til struktur:

```
/lab/koteudregner/index.html
```

Så kan den tilgås på:

- `https://<dit-domæne>/lab/koteudregner/`

## Tilføj link fra Lab-forsiden

På din `/lab/index.html` kan du fx tilføje et kort/link til:

- `/lab/koteudregner/`
